====================================================================================================
Step 9. Quorum arithmetic: does a read quorum of R see a write acknowledged by W?
====================================================================================================

  N = 3. The write reaches exactly W replicas (partition), then every read set of size R
  is asked; it returns the version with the highest timestamp.

    W  R  R+W  R+W>N   write acks  read sets  stale read sets  which
    1  1  2    no      1           3          2                {B} {C}
    1  2  3    no      1           3          1                {B,C}
    1  3  4    yes     1           1          0                -
    2  1  3    no      2           3          1                {C}
    2  2  4    yes     2           3          0                -
    2  3  5    yes     2           1          0                -
    3  1  4    yes     3           3          0                -
    3  2  5    yes     3           3          0                -
    3  3  6    yes     3           1          0                -

  Stale reads happen only when R + W <= N: then a read set can miss every replica of the write.
